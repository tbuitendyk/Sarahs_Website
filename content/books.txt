// ===================================================================
//  SARAH'S BOOKS
//
//  Every book card on the site comes from this file: My Books,
//  Anthologies, IGS: Files and the hidden subscriber page.
//  A book with a description also gets its own page automatically,
//  and its "Learn more" button opens that page.
//
//  TO ADD A BOOK: copy one of the books below, paste it where you want
//  it, and fill it in. Books show in the same order as in this file,
//  so put the newest first.
//
//      === my-new-book ===
//      Title: My New Book
//      Label: Novel · Romantic Suspense
//      Cover: my-new-book.jpg
//      Buy: https://www.amazon.com/...
//      Show on: My Books
//      Card text: A line or two shown under the cover on the lists.
//
//      The description goes here, after one empty line.
//      This is what appears on the book's own page.
//
//  WHAT EACH LINE DOES
//    === name ===  Starts a book. The name becomes the page's address,
//                  for example book.html#igs-1. Use small letters,
//                  numbers and dashes, and don't change it once people
//                  have the link.
//    Title:        The book's title.
//    Label:        Small gold words above the title (optional).
//    Cover:        The cover picture's file name, from the folder
//                  assets/images/covers/. Leave it empty for a
//                  "Cover coming soon" cover.
//    Buy:          The web address where people can buy it. Leave it
//                  empty and the Buy button stays greyed out.
//    Show on:      Which lists show the book: My Books, Anthologies,
//                  IGS: Files, Subscribers. Separate them with commas.
//    Card text:    Optional words under the cover on the lists.
//    Page:         Only for books that already have their own page.
//    Download:     Only for free stories: the file's name, from the
//                  folder assets/downloads/. Shows a Download button
//                  in place of Buy the book.
//
//  The description can use the same extras as blog posts: **bold**,
//  *italic*, [link text](https://...), "- " bullet points and "---"
//  dividers. If a book has no description yet, it has no page yet and
//  its Learn more button stays greyed out.
//
//  Lines that start with // (like these notes) never show on the site.
// ===================================================================
